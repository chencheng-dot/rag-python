# duobaan 项目说明

## 一、项目定位

一个面向个人日常事务的桌面助手，核心目标是把「记下来」和「做完」连成一条闭环。
它包含三个主要页面：流程表（今日/明日任务）、智能对话、我的（历史与知识库）。

## 二、技术栈

后端使用 Java 17 与 Spring Boot 4.1.1，数据库是 MySQL 8.0.46，缓存使用 Redis 3.2.100。
前端使用 Vue 3.5 与 Vite 6 构建，开发期通过 Vite 代理把 /api 请求转发到后端。

## 三、任务状态流转

任务状态包括 TODO、DOING、DONE、SUBMITTED 四种。
流程表只展示未完成的任务；标记为 DONE 的任务会立刻从列表移除。
「已上交」表示任务已归档留痕，软删除不会让它从历史记录里消失。

## 四、知识库与检索

知识库支持文本分块与向量化检索，默认把正文按 500 字切块、块间重叠 50 字。
检索时取相似度最高的 4 个切片拼进提示词，相似度低于 0.35 的切片会被丢弃。
向量存放在 Redis 中，正文存放在 MySQL 中，两者通过 chunkId 关联。

## 五、天气服务

天气功能依赖和风天气的 API Host，必须使用形如 xxx.qweatherapi.com 的个人域名。
旧的公共域名 geoapi.qweather.com 与 devapi.qweather.com 已停止服务。
天气信息默认缓存 600 秒，避免频繁请求上游。
